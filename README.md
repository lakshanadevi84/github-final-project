# Simple Interest Calculator

A simple program/script to calculate the interest earned or owed over a specific period.

## Formula Used
The simple interest is calculated using the standard formula:
**A = P(1 + rt)**

Where:
* **A** = Total Accrued Amount (principal + interest)
* **P** = Principal Amount
* **r** = Annual Interest Rate (decimal)
* **t** = Time Period (in years)

## How It Works
1. The user inputs the **Principal amount**.
2. The user inputs the **Annual interest rate** (as a percentage).
3. The user inputs the **Time period** in years.
4. The calculator computes the simple interest earned and displays the total amount.
